# Kid Games

Three tiny HTML games for Emi, made to play on the iPad while traveling.
No build step, no dependencies — each game is a single self-contained `index.html`
(except shared `sw.js` + icons, which make them installable and work offline).

- **Bubble Pop** → https://mitchmason4.github.io/kid-games/
- **Magic Match** → https://mitchmason4.github.io/kid-games/memory/
- **Emi's Dress-Up** → https://mitchmason4.github.io/kid-games/dressup/

On iPad: open a game in Safari → Share → Add to Home Screen. Open each game once
on Wi-Fi and it will keep working with no internet.

Made with love by Dada.
